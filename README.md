# Meu Site

Site estático inicial (HTML, CSS e JavaScript puros, sem dependências).

## Estrutura

```
index.html   Página principal
styles.css   Estilos (suporta modo claro e escuro)
script.js    Scripts da página
```

## Como visualizar

Basta abrir `index.html` no navegador. Ou, para um servidor local:

```bash
python3 -m http.server 8000
```

Depois acesse http://localhost:8000.
